06

Questions before you let a pig inspect your Mac.

Does the first scan close or delete anything?

No. Running machogs is report-only, and opening the app only looks. Closing a process or clearing a rebuildable cache requires a separate explicit action.

Can it close something I am working on?

Live Claude Code sessions are protected, along with macOS system processes and known productive work. Use machogs --check to audit those protections without touching anything.

Is the native Mac app downloadable?

Yes. Machogs is a free, Developer ID-signed universal app for macOS 13 or later. Download the DMG, or watch GitHub releases for the latest.

Does the app need an admin password or broad access?

No admin password, no Full Disk Access, no Accessibility access. Notifications and Start at Login are optional and explained in context.

Is it free?

Yes. The app and the command-line tool are open source under the MIT license.
